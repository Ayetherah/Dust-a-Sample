# What the *FUCK* is .1dpcm
.1dpcm is standin file format for my 1 bit, 192kHz ADPCM (Adaptive Differential Pulse Code Modulation) bullshit. It has absolutely no reason to exist on this god forsaken planet, but by god it does.

*Designed by me, implemented by an LLM, for I have heard that it sounds good.*
